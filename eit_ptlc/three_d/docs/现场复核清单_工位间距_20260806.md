# 现场复核清单: 工位间距与落点净空 (2026-08-06)

> **一句话**: 三维模型说"从展缸1取出的板放不进展缸5-8、点样座取的板放不进刮板台",
> 而实机取放没问题。这份清单把每一条分歧翻译成**卡尺/卷尺能量的标量**, 量回来就能定案
> 是 **CAD 摆错了** 还是 **示教点偏了**。
>
> 数据来源: `pipeline/diagnose_plate_grip.py` 的 `pairDistances` / `transfer` 两节
> (产物 `work/plate_grip_diagnosis.json`), 净空来自 `exports/TLC_full_native.glb` 逐顶点射线实测。

## 怎么读这张表

每条给三个数: **CAD 说多少** / **示教反推多少** / **差多少**。

| 量出来接近 | 结论 |
|---|---|
| CAD 值 | **示教点偏了** —— 机器人被教到了错的地方(但实机能跑, 说明偏得还在余量内) |
| 示教值 | **CAD 摆位错了** —— 三维模型该改, 实机没问题 |
| 都不接近 | 两边都有账, 需要单独查这一站 |

**中心距**指两个落点上"板的中心"之间的距离。现场不好直接找板心, 建议量**两个座各自的
同一个基准面**(例如两缸腔口的同一侧内壁), 再各自加半个腔宽换算 —— 只要两站用**同一种**
基准, 差值就是可比的。

## 3. 净空项: 判"放得进放不进"的尺子

上面那些差值要不要紧, 取决于座留了多少余量。以下是 CAD 值, **打星号的现场必须实测**。

| 落点 | X 向每侧 | Y 向每侧 | 纠偏机构 | 导入倒角 |
|---|---|---|---|---|
| 点样座沉台 | −X 1.0 / +X 3.5(气缸空程) | **1.0 / 1.0** | TCM6x5 气缸, 总行程 4.5mm, 推 −X | 无(1.5mm 直壁沉台) |
| 刮板台沉台 | −X 2.0 / +X 2.5 | **1.0 / 1.0** | 同上 | 无 |
| 展缸腔 | **5.0 / 5.0** | 7.0(远端)/ 28.0(溶液槽端) | **无** | **无**(直壁到缸口) |
| 料仓护板段 ★ | 0.00 / 0.00 | 0.00 / **−0.61** | 无 | 仓口 26mm 喇叭口, 2.0mm/侧 |
| 料仓调宽板段 ★ | 1.0 / 1.0 | 无约束 | 无 | 两端喇叭口 2.8~5.5mm/侧 |

要量的:
1. **点样座 / 刮板台 沉台 Y 向通道净宽** —— CAD 202.0mm(板 200 ⇒ 每侧 1.0)。
   这是全机最紧的一处, 也是"点样↔刮板 5.1mm 错配"要不要紧的判据。
2. **展缸腔 X 向净宽** —— CAD 210.0mm(每侧 5.0)。顺便确认**缸口有没有倒角**:
   CAD 里从缸底一路到缸口 136.0 都是直壁, 一点倒角都没有。若实机有倒角, "跨塔换缸放不进"
   的结论就要放宽。
3. ★ **料仓调宽板通道净宽** —— CAD 202.0mm。**这一项 CAD 完全不可信**: 零件名就叫
   "**调宽**板", 实机是可调的, CAD 只是画在名义位。
4. ★ **料仓护板净宽** —— CAD 200.0mm = **零间隙**(板 200.0 刚好塞满)。同上, 必须实测。
5. ★ **废板仓 −Y 侧护板内宽** —— CAD 里这块护板**压进板名义轮廓 0.613mm**(静态干涉,
   `work/plate_clearance.json` 里 axis_2z 从 5mm 到 280mm 每一档都记着 `depthMm: 0.61`)。
   这是 CAD 自身画错还是实机真这么紧, 量一下就知道。

## 4. 量回来之后怎么用

| 情形 | 处置 |
|---|---|
| #5/#8 量到 ≈864(CAD 对) | 示教点问题 ⇒ 不动三维, 记进"示教复核"待办 |
| #5/#8 量到 ≈852/856(示教对) | **CAD 塔B 摆位错约 10mm** ⇒ 给展缸塔B 补 `station_alignment`, 重跑三维重建链 |
| #5 与 #8 实测**不相等** | 塔装歪(上下端偏差不同) ⇒ 不能用单一平移修, 要按缸逐个对齐 |
| 净空项 ★ 实测远大于 CAD | 料仓那几条"零间隙/干涉"是建模理想化 ⇒ CAD 该按实测放宽 |

⚠ **在量回来之前, 不要动 `station_alignment`、不要动地轨零点、不要动示教点。**
理由见 `工位摆位偏差溯源_20260805.md` §三.4/§三.5 —— 拿落点残差反向驱动工位平移,
这个项目已经付过一次学费(工位被挪了 23~41mm 去补一个根本不属于工位的量, 门禁全绿而
模型离真机越来越远)。

## 5. 顺带: 地轨零点那 8mm 也在等现场

地轨零点现在是**由换刀位(P8/P9/P10)标出来的**, 与机器人基座 x 注册是同一次拟合的两个面
(残差 rms 2.01 / max 2.61mm)。若改从取板点重解, 零点要从 **500 → 491.96**(差 **8.04mm**)。

**但现有数据不支持这个解**: 同一个地轨槽位内的 dX 散布 **12.56mm**, 比两个槽位之间的
中位数之差 **0.89mm** 大一个量级 —— 真是地轨零点错, 同槽位的点应当整齐同向偏移。
更像是别处的常量偏差被地轨这个自由度吸收掉了。且地轨标度已两点法实测证实为 1.0
(838,860.8 inc/mm ↔ CFF10-L10-900 的 10mm 导程), 不是标度问题。

⇒ 想定案, 需要**在第三个地轨槽位(350mm)上补几个取放点观测**, 或现场直接量
"4 号工具位与 1/6 号位之间的实际行程"。
