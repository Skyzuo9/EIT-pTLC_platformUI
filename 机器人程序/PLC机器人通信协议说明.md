# PLC与机器人通信协议说明

---

## 一、通信协议概述

- 通信协议：**ModbusTCP**
- 双方通过指定的寄存器进行数据交互
- 机器人侧提供 `FunctionID` 及对应参数，PLC 侧通过通信写入信号控制执行

---

## 二、执行流程图（文字描述）

### 2.1 主执行流程

1. **触发执行**：PLC 将 `Execute` 信号置位（上升沿有效），机器人检测到上升沿后进入执行流程。
2. **读取参数**：机器人读取 `FunctionID` 寄存器，获取当前需要执行的函数编号；同时读取 `ParameterList` 寄存器组，获取对应的参数列表。
3. **条件判断**：机器人检查当前点位状态，判断是否允许执行当前函数指定的参数列表。
   - 若**不允许执行**：将 `ErrorID` 写入对应错误码（如 255 表示不允许执行），流程终止。
   - 若**允许执行**：将 `Status` 写入 `Busy`（运行中），将当前点位编号写入 `Point` 寄存器，进入运行状态。
4. **执行函数**：机器人在运行状态下执行对应的功能函数 `Function(Parameter)`。
5. **完成处理**：任务运行完成后，`Status` 写入 `Complete`（任务完成），`Point` 写入当前状态编号，等待 PLC 读取。
6. **释放复位**：PLC 检测到 `Status = Complete` 后，将 `Execute` 信号置低（下降沿）。机器人检测到下降沿后，将 `Status` 写入 `Free`（空闲），表示初始化完成，可接收下一次任务。

### 2.2 错误处理流程

1. 运行过程中发生报错时，`Status` 写入 `Error`（报错状态）。
2. PLC 可通过 `Read Reset` 读取复位信号。当 `Reset` 信号上升沿到来时，机器人将 `ErrorID` 写入相应的错误码。
3. 参数复位后，`Status` 写入 `Free`（空闲），`FunctionID` 置为 `0`，`ParameterList` 置为 `0`（参数初始化）。

### 2.3 轮询机制

PLC 侧需周期性轮询 `Execute` 执行信号，检测上升沿触发；触发后读取 `FunctionID` 和 `ParameterList` 参数列表，并查看当前点位状态，判断是否允许当前函数参数列表的执行。

## 三、寄存器参数表

| 参数 | 读写权限 | 数据类型 | 描述 |
|------|----------|----------|------|
| **Execute** | RW（读写） | INT | `0 (False)`：无触发；`1 (True)`：上升沿触发执行 |
| **Reset** | RW（读写） | INT | `0 (False)`：无复位；`1 (True)`：上升沿触发复位 |
| **FunctionID** | RW（读写） | INT | 取值范围：`0` ~ `255`，用于指定要执行的函数编号 |
| **ParameterList** | RW（读写） | 自定义（n 个寄存器） | 与 `FunctionID` 配套的参数列表，具体定义由应用层自定义 |
| **Status** | RO（只读） | INT | `0`：Free（空闲）；`1`：Busy（运行中）；`2`：Complete（任务完成）；`3`：Error（运行报错） |
| **Point** | RO（只读） | INT | `0`：原点初始化；`1` ~ `255`：自定义点位编号，反馈机器人当前点位 ID |
| **ErrorID** | RO（只读） | INT | `0`：无错误；`255`：不允许执行；其他值：自定义错误码 |

---

## 四、机器人通信需求

1. 采用 **ModbusTCP** 通信协议，通过 `FunctionID` 和对应参数列表实现功能调用。
2. 允许通信写入 `Execute` 执行信号，**上升沿有效**。
3. 允许通信写入 `Point` 点位状态反馈，用于反馈机器人当前所处点位 ID。
4. 通过 `Status` 寄存器反馈执行状态：空闲（Free）/ 运行中（Busy）/ 任务完成（Complete）。
5. PLC 需轮询 `Execute` 执行信号，检测上升沿后读取 `FunctionID` 和 `ParameterList` 参数列表，同时查看点位状态，判断当前函数及参数是否允许执行。

## 五、状态转换速查

| 当前状态 | 触发条件 | 下一状态 |
|----------|----------|----------|
| Free（空闲） | Execute 上升沿 + 条件允许 | Busy（运行中） |
| Free（空闲） | Execute 上升沿 + 条件不允许 | Error + ErrorID 写入 |
| Busy（运行中） | 任务完成 | Complete（任务完成） |
| Busy（运行中） | 运行报错 | Error（报错） |
| Complete（任务完成） | Execute 下降沿 | Free（空闲） + 参数初始化 |
| Error（报错） | Reset 上升沿 | Free（空闲） + 参数初始化 |
