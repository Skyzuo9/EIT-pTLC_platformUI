## 0. 范围与基准（务必先读）

**目标**：让连续伺服的自动目标值改由上位机经 PC 专用 flat 节点（`*_Target`）下发，PLC 把实际位置镜像回 `*_ActPos`；并新增地轨 `Rail_L2` 派发器。单写者：`*_Target` 只 PC 写、`*_ActPos` 只 PLC 写、HMI `position[]` 示教槽不动。

**唯一基准**：`eit_ptlc/plc/Now.xml`。其它目录（`PLCsoftware/OPCUAtest/*` 等）均为旧文件，**不看**。

**只改 L2 程序，legacy 一律忽略**。Now.xml 里上样/点样有两个并存程序：

| 程序 | objectGuid | 状态 | 本手册 |
|---|---|---|---|
| `Sample_point_sampling_上样点样` | `91a911e2…` | **legacy 旧程序** | ❌ 忽略（含 A40_absorb_liquid、A50_Spray_sample 等） |
| `Sampling_L2` | `7ccf92d0…` | **L2 新程序** | ✅ 只改这个（FSM 见 [Now.xml:2467](../eit_ptlc/plc/Now.xml#L2467)，`50→A50_absorb`、`60→A60_spray`） |
| `PhotoScrape_L2` | — | L2 拍照 | ✅ 8Y 拍照位在此 |

**前提**：`Sampling_L2` FSM **已存在**（[Now.xml:2330-2511](../eit_ptlc/plc/Now.xml#L2330)），已用 `RequestSeq→AcceptedSeq→CompletedSeq`/`State` 包住各 A 动作 → 起步闸直接挂它，**不必新建**。**唯一需新建的是 `Rail_L2`**（第 6 节）。

## 4. 起步闸 + `coordinate` 退役

`Sampling_L2` 的 A50_absorb 内仍有 `IF Sampling_X_coordinate>0 AND Sampling_Y_coordinate>0`（[Now.xml:68775](../eit_ptlc/plc/Now.xml#L68775)）作内层闸。退役 coordinate 后 PC 不再写它（恒值），此闸需改：

- A50_absorb 已由 `Sampling_L2` FSM 在 `State=RUNNING`（ActiveCode=50）下才调用 → **用 FSM 运行态/到位条件取代 68775 的 `IF coordinate>0` 内层闸**（或直接去掉，由 FSM 保证只在受理后执行）。
- 退役后 **PC 永不写 `Sampling_X/Y_coordinate`**。变量声明（[Now.xml:62430](../eit_ptlc/plc/Now.xml#L62430)/62438）可保留（恒 0）或清理。

> 注：coordinate 在旧 legacy 程序还另有"料架检测联锁"用途，**本轮不考虑**（legacy 不在范围）。

## 5. ActPos 镜像（新增 5 行，放无条件周期段）

每轴一行，镜像 `fActPos`（servo「实际位置」成员）。供上位机随时 jog 采点 + 实时显示：

```pascal
Sampling_4X_ActPos := 上样轴4X轴DATE.fActPos;
Sampling_3Y_ActPos := 打样瓶上料轴3YDATE.fActPos;
Spot_6X_ActPos     := 点样轴6XDATE.fActPos;
Spot_7Y_ActPos     := 点样轴7YDATE.fActPos;
Photo_8Y_ActPos    := 拍照轴8YDATE.fActPos;
```

> **关键**：放主循环**每周期必执行**的段，**不要**嵌在 `CASE step` 分支里（否则 jog 采点读到陈旧值）。只读、不参控制。

## 6. 新建 `Rail_L2` 派发器（唯一全新 POU）

地轨 11Y 现仅在 legacy 机器人流程内按编号召回（保留不动）；新增 `Rail_L2` 让上位机独立触发。

- **模板**：照 `Pump_L2`（[Now.xml:8332-8426](../eit_ptlc/plc/Now.xml#L8332)，单动作 L2-FSM，最简）。新建 POU 插在其后。
- **变量契约**：见第 1 节 13 个节点。
- **FSM 伪代码**：

```pascal
CASE Rail_L2_State OF
  0 (* IDLE *):
    IF Rail_L2_Start AND NOT Rail_L2_Start_prev THEN
      Rail_L2_AcceptedSeq := Rail_L2_RequestSeq;
      Rail_L2_ActiveCode  := Rail_L2_ActionCode;
      地轨轴11YDATE.fAbsTarget := HMI_地轨轴11Y.position[Rail_Target_Position]; (* 1..6 *)
      地轨轴11YDATE.xMoveAbs := TRUE;
      Rail_L2_State := 10;
    END_IF
  10 (* RUNNING *):
    IF 地轨轴11YDATE.bAbMoveDone THEN
      地轨轴11YDATE.xMoveAbs := FALSE;
      Rail_L2_CompletedSeq := Rail_L2_AcceptedSeq;
      Rail_L2_State := 20;
    ELSIF (* 故障 *) THEN
      Rail_L2_ErrorCode := …; Rail_L2_State := 40;
    END_IF
  20 (* DONE *): ;   (* 等 PC 取走 / 下一请求 *)
  40 (* ERROR *):
    IF Rail_L2_Reset THEN Rail_L2_State := 0; END_IF
END_CASE
Rail_L2_Start_prev := Rail_L2_Start;
```

- **位置码**：1上样点样 / 2刮板拍照 / 3收集暂存 / 4取工具 / 5展开 / 6收集货架仓库。
- **legacy 11Y 召回保留不动**（地轨真值在 HMI 槽，Rail_L2 仅加独立触发通道）。
