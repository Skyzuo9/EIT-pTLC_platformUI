# 全流程 demo 审阅与地轨/换刀/握手修复 (2026-07-03)

## 目标

对新写的全流程单样品 demo (`config/operation/10_demo/single_sample_demo.yaml`, 四段式 + 显式
handoff + 耗材板, 尚未上机验证) 做静态审阅, 对照旧已验证 `UI-Upper/` 流程, 重点核对**机器人
动作前的末端工具态、地轨位、PLC 握手**。本轮暂不考虑多样品并发。

## 方法

多智能体工作流 (3 参照层: 旧机器人层 / 旧工艺握手层 / 姊妹 `ptlc_full_v2` 显式移轨清单 →
12 分段审阅 → 跨段接缝审阅 → 逐条对抗性验证): 28 候选发现 → 21 存活 → 与用户逐条对齐**物理
真值**后收敛为真实缺陷并修复。

## 关键结论 (物理地轨位真值, 用户 2026-07-03 现场确认)

- **暂存A = 位2** (≡刮板拍照/上样, 168.0; 位1≡位2 同物理点)
- **暂存B = 位3** (≡收集站, 350.0)
- **货架/仓库 rack = 位6** (600.0)

货架侧与暂存侧**不同轨**, 故整组 rack↔staging 搬运必须**两段移轨**。原 4 个整组 transfer 的
注释 `货架/暂存同地轨位(位6)` 是错的, 且只 `rail_move_safe(6)` 一次就在位6 完成两侧动作 →
暂存侧抓/放偏 432mm(收集器)/250mm(瓶)。

## 改动

### #1 暂存料巢地轨位 (上机前 blocker)

| 文件 | 修正后地轨序 |
|---|---|
| `transfer_collector_rack_to_staging_a` | 位6 取货架 → 位2 放暂存A |
| `transfer_collector_staging_a_to_rack` | 位2 取暂存A → 位6 放货架 |
| `transfer_bottle_rack_to_staging_b` | 位6 取货架 → 位3 放暂存B |
| `transfer_bottle_staging_b_to_rack` | 位3 取暂存B → 位6 放货架 |
| `collect_unload` 收集器还回 | 补 `rail_move_safe(2)` (原继承位3 错) |

(单件收集器暂存A取/放走位2、单件瓶暂存B走位3 二链本就正确, 未改。)

### #3 收集器放入刮板夹具后先夹紧再松爪 (plan B)

原: 机器人放入即松爪退出, 下压气缸要到 `photoscrape_process` 开拍前才压 → 收集器"自由态"
可能移位。改: 微调对位段从 `robot_scrape_holder_put_exit` 前移到 `robot_scrape_holder_put_enter`;
`put_exit` 只留松爪+退回; `transfer_collector_staging_a_to_scrape` 在两者间插
`photoscrape.press_cylinder(true)` 夹紧, 并补 `station:photo_scrape` 资源。
(注: `powder_collector_locator` code36 当前配置不存在; 夹紧靠 `press_cylinder` code33。)

### #4 起手工具态对账

`single_sample_demo` 起手 HITL 提示词加"确认末端已空 (吸盘无残留板/夹爪无残留件) + 实物挂载
工具与 `robot_tool_state.json` 记录一致"。前提: 工具态真源信状态文件, 仅补一道开机人工门防
文件陈旧。

### #5 phase 自守卫地轨 (保险 + 拆雷)

`sampling_load`(位1) / `sampling_unload`(位1) / `collect_load`(位2) 各补幂等 `rail_move_safe`,
使 step 可单独点跑并防上游遗留错位。顺带**自动拆除 `ptlc_full_v2.yaml:82` 的
`rail.move(3)` 会让 collect_load 首步取收集器在位3 撞刮板夹具的雷**。
