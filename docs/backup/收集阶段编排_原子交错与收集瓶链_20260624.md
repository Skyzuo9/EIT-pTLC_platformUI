# 收集阶段编排 — 原子交错与收集瓶链 (缺口A5)

> 文档定位: **设计 + as-built**。日期: 2026-06-24 · 来源: 0624 grilling (operation 复刻核对)
> 关联: operation 复刻缺口核对 (缺口A5)。

## 1. 问题
旧 PLC `Collection_process` 在内部把"气缸步进 ↔ 机器人放瓶/取瓶(FID15/13)"**同步触发**。上位机直驱机器人后，这套交错必须在**编排层显式重排**，但原 `collect_full` 把 `init→…→release_clamp` **打包成黑盒**，导致:
1. **收集瓶链整条没编进** v2 → 洗脱液无瓶接、成品没人取。
2. `extend↔lift_press`(应放瓶)、`transport_extend↔retract`(应取瓶) **无插入缝**。
3. `transfer_collector_scrape_to_collect` 末尾已 `clamp`，`collect_full` 开头又 `init`(复位会松掉收集器)+`clamp` → **init/clamp 错位**。
4. 收集器在 v2 里被放到 `photoscrape` **之后**才入刮板夹具 → **接不到刮下的粉**(旧 FID100→刮取→FID110 证实须刮前就位)。

## 2. 正确交错序列 (复刻旧时序)
| # | 动作 | 类型 | 备注 |
|---|---|---|---|
| 1 | `collect.init` | PLC | 复位气缸/阀+泵; **须在放收集器前** |
| 2 | 放收集器 (刮板夹具→收集夹具) | 机器人 | `robot_collect_holder_put_enter`/`_exit` (纯机器人) |
| 2b | `collect.clamp` | PLC | 收集器放到 P73 夹具后**夹紧**; 现归 `collect_cycle` 内显式调 |
| 3 | `collect.extend` | PLC | 伸出让位 |
| 4 | `transfer_bottle_staging_b_to_collect` | 机器人 | **放瓶** |
| 5 | `collect.lift_press` | PLC | 缩回/升降/下压 |
| 6 | `collect.collect` | PLC | 洗脱循环 (液入瓶) |
| 7 | `collect.transport_extend` | PLC | 复位+伸出让位 |
| 8 | `transfer_bottle_collect_to_staging_b` | 机器人 | **取瓶(成品)→暂存B** |
| 9 | `collect.retract` | PLC | 缩回 |
| 10 | 取收集器 (收集夹具进) | 机器人 | `robot_collect_holder_pick_enter` (纯机器人) |
| 10b | `collect.release_clamp` | PLC | 取收集器前**松夹**; 现归 `collect_cycle` 内显式调 |
| 10c | 取收集器→暂存A | 机器人 | `robot_collect_holder_pick_exit` + `robot_collector_return_put` (纯机器人) |

> **as-built (CL-1/R2)**: `clamp`/`release_clamp` 是 collect 本站动作，已从两 collector transfer 移入 `collect_cycle.yaml` 内显式调用 (收集器放上 P73 夹具后 `clamp`，取回收集器前 `release_clamp`)；两 collector transfer (`transfer_collector_scrape_to_collect` / `transfer_collector_collect_to_staging_a`) 已降为**纯机器人 + 地轨** 并退役 (`[已退役 R2]`，零引用)。

## 3. 落地
- **新增** `config/operation/05_collect/collect_cycle.yaml` = 上表交错编排 (参 `collector_slot`/`bottle_slot`)，**取代黑盒 `collect_full`**。
- **改** `ptlc_full_v2.yaml`:
  - 收集器入刮板夹具(`transfer_collector_staging_a_to_scrape`) + 瓶预备(`transfer_bottle_rack_to_staging_b`) **前移到 `photoscrape_full` 之前** (接粉)。
  - 收集段用 `collect_cycle` 替换 `collect_full` + 散落的 collector transfer。
  - 工具边界(缺口C)不变: 备耗材前 `吸盘→小夹持`、收尾废料前 `小夹持→吸盘`; `photoscrape`+`collect_cycle` 同处小夹持区(photoscrape 无机器人)。
- `collect_full` 保留但标弃用 (仍被 `test_stations_l2_offline` 引用)。

## 4. 前提与待验 (真机 T)
- **地轨与站气缸解耦**: 单轴 11Y 离散召回 6 位 (上样/拍照同 168、展开/仓库同 600)，地轨只移机器人到工位区; `collect.*`/`photoscrape.*` 站内动作与地轨位无关，机器人 transfer 自管 `rail.move`。**若真机站动作依赖地轨位，需在站原子前补 `rail.move`。**
- 刮板夹具夹/松收集器目前是占位(无独立 L2 原子) — 真机握手待验收。
- `collect.lift_press` 缺瓶报错 201 → 验证步4 放瓶确实在 lift_press 之前生效。
