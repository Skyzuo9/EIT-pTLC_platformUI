## 一、执行摘要

这套 UI 的工程底子明显好于多数同类项目: 40+ 语义色令牌 + 深浅双主题、零 `outline:none`、零 `transition:all`、空状态几乎处处带下一步指引、点动安全逻辑(`useAxisJog.js` 三层防卡死)达到产品级水准。**但四类系统性缺口与其形成鲜明反差**:

1. **安全确认体系外包给浏览器**: 31 处 `window.confirm` + 5 处 `alert` 承担全部硬件安全确认(浏览器"阻止此页面显示更多对话框"可一键静默全部安全闸门), 且「执行硬件动作」「应用到生产」「SSH 停远端服务」「整板清空」等十余处高危操作完全无确认; 全局急停按下零可见反馈; 报警横幅(fixed z-3000)会盖住急停按钮。
2. **可达性近乎缺席**: aria 覆盖率 1.7%(7 处/420+ 交互元素); 50 处 div 当按钮(整个左栏导航纯鼠标可用); 全仓 `label for=`/`id=` 配对数为 0; aria-live 仅 1 处; 4 个弹窗全部无焦点管理, HitlModal(阻塞机器的人工决策门)连 Esc 都没有。
3. **约 13 个确定性 bug**: HitlModal 提交 bbox 与所见不符、ValueInput 非法输入静默变 0(机器参数)、物料录入 blur 丢数据、标定画布拖拽卡死、跨 scoped 死类、令牌未定义等。
4. **一致性失散**: 危险按钮四套样式且「急停」与普通按钮同视觉权重、`...`/`…` 混用、数字列无 tabular-nums 跨行不对齐、20+ 处 setInterval 不随页面隐藏暂停、字号令牌未渗透到组件层(283 处硬编码 font-size)。

修复按「共享原语先行 + 按模式批量收敛」组织(§五), 本轮实施 P0-P2 并将触屏可达性并入(现场有触屏/平板操作), P3/P4 列入后续路线(§六)。

## 四、系统性结论(修复按模式批量做, 不逐文件流水账)

1. **确认体系**: 31 confirm + 5 alert + 4 prompt 是全部机制, 无自建组件; 高危无确认十余处; 正模板 CompilePanel:216-229。→ confirmService 分级确认(§五)
2. **div@click**: 50 处遍布主交互路径(ExplorerDock 22 处/页签/行选/断点); 正例 RailNav 可照抄。→ btn-bare 批量法
3. **表单标签**: 全仓 for/id 配对 0; 60+ 控件无可访问名; 包裹式正确写法与失联写法两套惯例并存, 新代码随机继承。→ 包裹为主 + aria-labelledby 为辅
4. **纯色彩传状态** 8 处(StatusBar 四裸数字最严重), 正例同样丰富(形状/条纹/文案随状态)——原则已掌握应用不均。→ 补第二编码
5. **aria-live** 全仓 1 处; 机器人运动进度/PLC 下载结果/急停反馈全静默。→ announcer 单例 + useAsyncAction 自动播报
6. **危险视觉与连发**: 危险样式四套且 .tb.danger 只改文字色; RobotJogPanel 8 方法零连发保护。→ 两级 danger 体系 + useAsyncAction
7. **长按/点动**: 安全逻辑一流, 键盘可达性为零且无替代路径提示。→ 政策: 键盘只走有界单发(§五决策6)
8. **禁用理由塞 title**(AT 不可达); 正解 CompilePanel:202-206 可见文本。→ .hint 推广
9. **焦点**: 样式基线好, div 不匹配规则。→ 焦点环扩围 + 语义化
10. **动效**: 零 reduced-motion, 6 个 infinite 动画; AlarmBanner 双 paint 动画最贵。→ 全局降频块 + opacity 化
11. **触屏**(现场有触屏): 零 touch-action:manipulation、零 overscroll; Splitter/水位标定 mouse-only; hover-only 入口; 约20px 触点承载危险操作。→ P0-P2 并入
12. **性能**【P3】: 虚拟化零处; 14+ 轮询无可见性暂停; 遥测整表重渲。
13. **列表 key**: 可重排列表索引 key 三处未修(正解已在仓内)。
14. **排版**: `...`/`…` 分裂 20+ 处; tabular-nums 仅 3 处; Intl 零处。

### 关键设计决策(定案)

1. 确认服务 = 模块单例 + Promise, `if (!(await confirmAction(...))) return` 与原 confirm 同构可逐行替换。
2. 危险分级: normal=丢弃草稿; danger(实底红)=删除/覆盖/终止/执行硬件动作/切 DEBUG; danger-ack(+强制勾选±探测)=写标定盘/写 PLC Target/SSH 停服务/应用到生产/释放急停/快换松开。**急停触发永不确认, 急停路径上不许出现对话框**; DO/夹爪高频调试用 arm 两段式(按钮原地"再点一次确认", 3s 撤防)防确认疲劳。
3. 急停反馈: 本地 busy("急停下发中…")+ assertive 播报; 结果以 telemetry 权威状态位驱动 engaged 样式(显示设备真相非请求回执); 失败播报"请使用物理急停"。
4. AlarmBanner 改文档流推压(#app flex column): 报警时整体下移, 急停永不被盖; 模态 backdrop 期间 UI 急停仍被挡为已知遗留(物理急停是权威路径), 列 P4。
5. div→button 批量法: li 内塞 `<button class="btn-bare">`, 样式选择器单点改; NodeRow 例外走 pressable(嵌套交互非法)。
6. 键盘点动政策: 按住点动保持 pointer-only(deadman 的键盘 keyup 可靠性不足, 且禁止前端定时 stop 模拟——与三层看门狗语义冲突); 键盘路径=有界单发(步进/目标位表单); 聚焦时可见 hint 明示替代路径。
7. HitlModal 只接行为层(useModalA11y+aria 标记), 不动 DOM 结构——合规改造不碰安全关键路径 DOM。
8. announcer 全局单例(v-if 局部 live region 挂载时序不可靠); 常驻置换的校验区例外用 role=status。
