# Rf 测量 · 真机测试与落地 · 数据采集清单

日期: 2026-07-09
分支: codex/ui-upper-next
相关: docs/superpowers/specs/2026-07-09-rf-measurement-design.md · docs/superpowers/plans/2026-07-09-rf-measure-phase1.md

> 落地前的数据 = 逐条**证伪设计假设** + 给两个常量喂真值。所有判据锚在误差预算 **Rf ±0.012**（1mm 放板 / ~40mm 前沿 → D_f 2.5%）。

## 0. 前置（最先做，否则后面全作废）

- **相机位置锁定**: develop 8 路 + scrape 相机物理固定、对焦/曝光冻结。
- UV 光源(254nm)强度、放板固定点位一并冻结。
- 这是所有标定/采图的前提，不是实验本身。

## 1. Phase 0 — spot 分割可行性（GATE）

| 项 | 内容 |
|---|---|
| 目的 | scrape 相机能否在真 UV 板稳定分斑点，且不被暗基线/暗边污染 |
| 采什么 | 真实已显影 UV 板图（scrape、锁定后拍），覆盖：弱斑/低浓度、拖尾、重叠、多 lane、不同 Rf 段(近原点/近前沿)、含原点暗基线 |
| 样本量 | ≥ 20~30 张，含最难样本 |
| 怎么用 | `rf_spot_check` 叠加图肉眼核验；统计漏检/误检 |
| 判据 | 真斑召回 ≥95%，暗基线/暗边不误判(调 darkness_k / min,max_area_frac / 加原点 band 屏蔽)。不过 → 先改成像(UV/曝光/偏振)或加物理手段，**不进 Phase 2** |

唯一真风险，先探。顺带定 `detect_spots` 三参数默认值。

## 2. 关键假设量化（决定 D_f-常量方案生死）

**① 放板重复精度** —— 解锁"origin 一次性常量"
- 采: 同板机器人取放 N≥15 次，每次 scrape 拍，量原点/板边在板归一化系位置。
- 判据: 板归一化 σ 换算 ≤1mm。

**② percent 阈值 → 前沿位置可重复** —— 解锁"D_f 是常量"（最关键）
- 采: M≥10 块板，同通道/ROI/阈值展开，触发即标湿态前沿 → scrape 拍 → 量原点→前沿(板归一化)。
- 判据: 前沿位置 σ 换算 ≤1mm(D_f 抖动 ~2.5% → Rf ±0.012)。**σ 明显更大 → D_f-常量不成立**，回退 develop 侧逐次前沿度量(设计 §9-4)。**最该早测。**

**③ 8 通道 D_f 是否一致** —— 解锁"单全局常量 vs 每通道"
- 采: 每通道各 2~3 块 ②标定板，比 D_f。
- 判据: 通道间差 < Rf 容差 → 单全局常量；否则逐通道存。

**④ 相机正对度** —— 解锁"bbox 仿射足够，不用单应"
- 采: 板平面放已知刻度直尺，横竖各拍，看板归一化尺度全窗是否恒定。
- 判据: 一致性 <~1% → 仿射够；否则 Phase 3 加单应(设计已留 YAGNI 口)。

## 3. 两常量真值标定（Phase 2 落数）

- **origin_frac**: (a) 点样伺服位置→板坐标换算 与 (b) 一次实测点样线板归一化位置，二者互验；用①数据验稳定性。落 `config/`。
- **D_f**: 即 ②/③ 实测原点→前沿板归一化值(每通道或全局)。落 `config/`。

## 4. 端到端 Rf 精度验收（决定能否上生产）

- 采: K≥10 块真实样品板走完整流程(develop 阈值触发 → scrape → 管线出 Rf)；同时人工尺量原点→前沿、原点→各斑点 → 人工 Rf 作 ground truth。
- 判据: 管线 Rf vs 人工 Rf 差 **≤ ±0.02**，逐斑点比(非只比均值)。
- 附带定: `axis` / `direction` / flow 朝向 —— 从真帧直接读定，写 config。

## 优先级 / 依赖顺序

```
相机锁定 ─▶ Phase0 spot 可行性(GATE)
              │过
              ▼
     假设② 前沿可重复(最关键，不过则架构回退)
              │过
              ▼
     假设①③④ + origin_frac/D_f 标定
              │
              ▼
     端到端 Rf 精度验收(K 块 ground-truth)
```

**一句话**: 先锁相机 → 先证 spot 分得出(Phase0) → 再证前沿可重复(假设②，决定 D_f-常量架构生死) → 才谈标常量与端到端验收。
