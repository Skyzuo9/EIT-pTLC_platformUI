## 1. 基准差定义

刮板位取板点从 P64 改为 P65(取放同点)后, 吸附点在板面上移动了:

```
v = P65 - P64 = (20.900024, 7.100002, 0.164551) mm,  |v| = 22.0737 mm
参考姿态 yaw_ref = P64.rz = -111.052383 deg (rotary-up, 板水平)
```

历史来源: 该向量与点样位已弃用的 P20-P19 = (-20.9, -7.1, -0.165) 精确互为相反数,
均为集成商手输圆整值; P64/P65 关节数组逐位相同(克隆铁证)。点样位的 22mm 有 7Y 载具
移位正当性, 刮板位没有 —— 这就是当年吸附基准跳变的根源。

## 2. 终版换算公式 (v4, 真机验证)

对**下游继承旧基准的点**(即按"P64 偏下夹持"示教的点), 迁移到新基准(P65 板中心夹持):

```
mapped  = Rz(点.rz - P64.rz) · v_xy          # 基准差按法兰 yaw 差整体旋转
mapped' = Mirror_插入轴(mapped)               # 仅 rotary-down 目标: 沿该工位插入轴镜像
新 xy   = 原始示教 xy + mapped'               # 永远从已验证示教值锚定
新 z    = 原始示教 z                          # v 的 z 分量 0.165mm 低于示教分辨率, 忽略
```

**关键规则(每条都曾以一轮真机试错为代价):**

1. **rotary-down 目标必须镜像, rotary-up 目标不镜像**。rotary-down 是 180° 翻转
   (吸盘从"托板朝上"翻成"持板朝下"), 180° 翻转把向量镜像: 沿翻转铰链轴的分量
   (映射到插入方向, ≈21)不变, 垂直分量(横向, ≈6.8)**变号**。v3 就是漏了镜像。
2. **不是"沿板上缘 +Z"**。竖直持板时基准差落在水平面(插入轴+横向), 不在 Z。v1 教训。
3. **不是"纯插入方向"**。基准差是刚体向量, 横向分量真实存在(±6.8)。v2 教训。
4. **永远从原始/已验证示教值重算, 不得在上一轮数值结果上累积**。
5. 吸盘工作方式: 点样/刮板/上料位从**板下方托板**(rotary-up, 取板进近点在目标下方
   -30 即此因); 展缸/下料放板前翻转 180°(rotary-down)持板朝下。

## 3. 调整方向速查表

| 工位 | 点位 | rz(deg) | 插入方向 | 镜像后修正向量 (x, y) | 含义 |
|---|---|---|---|---|---|
| 缸塔A | P11-P14 | 158.13 | **-Y** | **(-6.80, -21.00)** | y 负=更深入; x 负=横向 |
| 缸塔B | P15-P18 | -21.75 | **+Y** | **(+6.85, +20.98)** | 与塔A 镜像对称(yaw 差 179.88°) |
| 下料 | P22 | -111.55 | **+X** | **(+20.96, -6.92)** | yaw≈刮板位, 插入分量在 X |

校验锚: 塔A 的映射结果 (6.80, -21.00) 是圆整值, 与手输 20.9/7.1 同源 —— 算出来不圆整
说明代入的 yaw 或符号错了。

## 4. 真机现象诊断树 (实测 → 结论 → 动作)

| 真机现象 | 结论 | 动作 |
|---|---|---|
| 高度错 22mm 且插入深度没变 | 轴向映射错(v1 型: 误设 +Z) | 回到公式重算 |
| 深度对, 横向偏 ~7mm | 缺横向分量(v2 型) | 补镜像后的横向分量 |
| 横向偏**同侧翻倍**(7→14mm) | 横向**符号反**(v3 型: 漏镜像) | 横向取反 |
| 横向偏**换了一侧** | 刚体模型失效 | 停止数值推导, jog 到正确位 capture 实测定标 |
| 细微偏差 ≤2mm | 数值通道已到精度地板 | 示教闭环收尾(见第 6 节), 不再数值迭代 |

## 5. 残差项清单 —— 为什么 v4 之后不再数值优化

v4 在三条理想化假设下是精确恢复; 细微残差(≤2mm)来自假设与真实机构的差:

1. **姿态差未映射(主项, ~0.5-2mm)**: P64/P65 姿态差 Δrx=0.334°, Δry=0.843°,
   Δrz=-0.795°。新夹持相对旧夹持不只平移了 v, 还带 ~0.8° 持板转角; 板绕吸盘转 0.8°
   板缘位移 ≈ 半板长 × sin0.8° ≈ 0.7-1.4mm, 另有 TCP 杠杆项。
   **纯平移编辑在原理上无法消除旋转项** —— 这是数值通道的精度地板。
2. **镜像轴按世界轴近似(≤0.6mm)**: 精确模型应绕唯一翻转铰链轴镜像; 三工位反推的
   隐含铰链方向(对世界X 0.50°/0.70°/0.82°)互差 ~0.3°, 按各自世界插入轴镜像引入
   亚毫米误差。取"最优单一铰链"重算收益 <0.2mm, 不值得。
3. **v 的 z 分量 0.165mm 忽略 + 展缸托架倾角耦合(≤0.3mm)**。

结论: 残差合计与真机实测"细微偏差"量级吻合, 数值层已打到地板。**不要再做盲数值迭代,
尤其不要试图数值映射姿态差**(姿态合成的约定风险远大于 <2mm 收益)。

## 6. 收尾与未来迁移规范

- **收尾**: 对仍有细微偏差的点走示教闭环(点位面板 capture → teach_plan/teach_move
  复核 → commit), commit 会用真实反馈同时刷新 pose 与 joint 并盖 calibrated_at,
  一并消除"pose 预置 / joint 未刷新"的半新态(9 点 allowed_motion 已收窄 move_l,
  joint 归真后如无需 move_j 维持收窄)。
- **commit 之后**: robot_points.json 即新真值, 本文的"原始示教值"锚随之过期;
  若再有基准变更, 以当时已验证值为新锚。
- **未来任何点位数值迁移的固定模式**: 一次性脚本入库(审计) + 当前状态快照防重跑守卫 +
  逐点分量符号核对 + PointRegistry 临时文件全量校验通过才写盘 + --dry-run 先核对 +
  真机低速逐点复核。守卫不变量由 `tests/test_pickput_basis_consistency_offline.py`
  锁定(同工位取放同基点, P64/P20 封印), 它锁配对关系不锁绝对数值, 示教 commit 不会破坏它。
