# 刮板对刀(对位检查)业务操作手册

面向操作员。目的:换刀之后,用刀头本身去核对刮取坐标系有没有对准物理板,
从而把「刮出来的带相对手绘/预期偏移」的责任分清楚是相机侧还是机床侧,并给出可以照抄的修正值。

对应实现:
- 业务流程:`eit_ptlc/config/operation/03_photoscrape/photoscrape_tool_align.yaml`(界面标题「刮板-对刀(对位检查)」)
- 对位内环:`eit_ptlc/config/operation/03_photoscrape/photoscrape_align_loop.yaml`
- 回显/Δ/建议值计算:`eit_ptlc/controller/align_check.py`
- 设计依据:`docs/superpowers/specs/2026-07-16-photoscrape-align-check-design.md`

## 0. 开工前必读的两条硬约束(安全红线)

### 0.1 PLC 动作尚未下装到真机 —— 现阶段真机禁跑

对刀用到的三个机床动作 —— 对位移动、对位回零、检查高度缓降/回升
(在 PLC 里对应动作码 ActionCode 42 / 43 / 44)—— **目前还没有实装并下装到 PLC**。
落地这套 PLC 逻辑的任务(内部代号 B11)因为现场 CODESYS 会话被操作员手动接管而被卡住,还没重新跑完。

因此:**在这三个 PLC 动作确认下装成功之前,不要在真机上启动「刮板-对刀」这个流程,
也不要在任何生产流程的门里点「对位检查」。** 在离线仿真里点没问题;一旦连着真机而 PLC 侧没有这三段逻辑,
上位机发出的移动指令要么无响应、要么走到意料之外的位置。

判断是否已下装:让维护人员确认 PLC 工程 `eit_ptlc/plc/20260702.project` 里
`PhotoScrape_L2` 已经包含动作码 42/43/44,并已成功编译下装、Symbol 表已导出 6 个新节点
(3 个目标节点 + 3 个 ActPos 只读回读节点)。

### 0.2 换刀后第一件事:先改 `plate_surface_z_mm`,再跑对刀

「检查高度」是靠配置里的板面高度 `plate_surface_z_mm` 减去余量算出来的(见 §2)。
如果换了一把更长的刀而没有先更新 `plate_surface_z_mm`,那么「缓降检查高度」会把刀直接怼进板里撞板。

流程的第一道确认门(首门)就是专门拦这件事的 —— 它会强制你确认「已按当前刀更新 `plate_surface_z_mm`」。
**这道门是防撞板的唯一防线**,不要盲目点确认。

## 1. 什么时候用、它能解决什么

**什么时候用:** 每次换刮刀之后,做一次对刀标定;平时怀疑刮取坐标漂了也可以复核。

**它解决什么:** 真机上观察到「刮出来的带」相对「手绘/预期的带」有一个固定方向的偏移。
这个偏移可能来自两处:

- **相机侧**:标四个角、把照片像素换算成板上厘米坐标那一步没标准(这部分交给矫正图上的原点标注去核对,不在本手册)。
- **机床侧**:对刀没对准,也就是配置里的刮取原点 `plate_origin_x/y` 和刀尖装配偏置。**本手册专门核对这一侧。**

做法:让刀头自己走到「程序认为的板角」上方,你用眼睛比对它和「物理板角」差多少,
差值(Δ)直接告诉你 `plate_origin` 该改成多少。

**参照物是物理板角。** 具体就是拍照标注图里用金色双圈标出来的那个角 —— 也就是点样边所在的那个角。

## 2. 几个名词(操作前先对齐语言)

- **Z 方向约定:** 本机 Z 正方向是**向下**。`Z=0` 是最高的安全位(在板正上方)。Z 数值越大,刀头越往下越靠近板。

- **检查高度(inspect Z):** 刀头缓降下去做目视比对时停的那个高度。它不是随便定的,而是算出来的:

  ```
  检查高度 Z = plate_surface_z_mm − align_clearance_mm
  ```

  也就是「板面高度」往上抬「一个余量」。物理含义 = 刀尖悬在**板面上方 `align_clearance_mm` 毫米处**,不碰板。
  当前刀:板面 `plate_surface_z_mm ≈ 20.5`,余量 `align_clearance_mm = 2.5`(默认值),所以检查高度 ≈ 18。
  换刀时**只需要改 `plate_surface_z_mm`**,检查高度会自动跟着变(余量 `align_clearance_mm` 是维护参数,一般不动)。
  这两个值都在配置文件 `eit_ptlc/config/app.yaml` 的 `gcode` 段。

- **原点角(plate_origin):** 配置里的 `plate_origin_x` / `plate_origin_y`,是程序认为的「板的坐标原点角」的机床坐标。
  它就是刮取坐标系的锚点,也是本次对刀唯一要修的量。当前值 `plate_origin_x ≈ 91.24`、`plate_origin_y ≈ −75.2`。

- **Δ(偏差):** 门顶回显里给的 `Δ=(Δx, Δy)`,含义是「刀头当前实际位置(ActPos 实读)− 程序指令的原点角」。
  对准物理板角之后,Δ 就是原点角标错了多少。

- **ActPos(实读位):** 三个刮板相关轴的实际位置回读值(X/Y/Z)。门顶回显里的「当前 X/Y/Z」就是它。

## 3. 完整流程:换刀 → 标定 → 验收

> 术语对照:下面「门」指界面上弹出的人工确认/选择框(human gate),操作员在框里点选项或填数。

### Step 0 —— 换刀,并先改配置

1. 物理换刀。
2. **先去配置页,把 `gcode.plate_surface_z_mm` 改成当前这把刀对应的板面高度**(见 §0.2、§2)。这是防撞板前提。
3. 在刮刀夹具里人工放一块板(任意板都行,板角的物理位置由定位夹具保证一致)。

### Step 1 —— 启动「刮板-对刀」

在界面 PhotoScrape 工位维护类里找到「刮板-对刀(对位检查)」并启动。
(它占用 `station:photo_scrape` 资源,和生产 run 天然互斥 —— 生产在跑时启动不了,反之亦然。)

### Step 2 —— 首门确认(防撞板唯一防线)

弹出的第一道确认门会让你确认两件事:

1. **`plate_surface_z_mm` 已按当前刀更新**(没更新的话,后面缓降检查高度会撞板);
2. 已在夹具里放好一块板。

两条都确认无误再点确认继续;有疑问就点取消 —— 取消时板还没夹持,不需要任何释放动作,流程干净退出。

### Step 3 —— 自动压板

确认后,流程自动落定位气缸并压下压板(对刀状态 = 工作状态,压平防止板翘)。这一步不用你操作。

### Step 4 —— 进入对位内环,走原点角并缓降

进入对位内环后,门顶会显示一行回显文字(内容见 §4),下面是六个选项:
**走原点角 / 走路径起点 / 缓降检查高度 / 升回安全高 / 微调(Δx/Δy) / 结束对位**。

标准对刀顺序:

1. 点「**走原点角**」——刀头先升到安全位 `Z=0`,再在 `Z=0` 高度平移到程序认为的原点角正上方。
   (维护场景没有刮取路径,所以「走路径起点」这个选项在对刀流程里是空转,点了不动 —— 正常现象。)
2. 点「**缓降检查高度**」——刀头缓慢下降到检查高度(板面上方约 2.5mm),停住,方便你目视。
3. 低头**目视比对**:刀尖和物理板角(金色双圈那个角 / 点样边角)差多少、往哪个方向差。

### Step 5 —— jog 微调,把刀尖对准物理板角

**关键安全规则(务必按这个姿势):一切 XY 平移都只在 `Z=0` 安全位发生,绝不在低位横着挪刀。**

所以微调是一个「看—抬—盲步进—再看」的循环,不是在低位一点点蹭:

1. 在检查高度**看**清楚偏差方向和大小(比如「刀尖比板角偏 +X 约 1mm、偏 −Y 约 0.5mm」)。
2. 点「**微调(Δx/Δy)**」,在弹出的输入框里填步进量 `ΔX` / `ΔY`(单位 mm,可以填负数,留空按 0)。
   系统会**先把刀升回 `Z=0` 安全位,再在高位平移**这个步进量。这一步是「盲步进」——移动时刀在高处,你看不到板角细节,这是安全代价。
3. 平移完刀停在 `Z=0`。再点「**缓降检查高度**」下来复查。
4. 还没对齐就重复 2–3,一次比一次步进小,**迭代收敛**,直到刀尖正对物理板角。

> 为什么不能在低位直接微调:低位横移会和机床既有的安全互锁冲突(刮板 Z 轴不在零位时禁止 XY 绝对运动),
> 而且低位盲挪有撞板风险。所以设计上把「低位 ≤2mm 微调」这种做法**取消**了,统一改成上面这个升 Z 循环。

需要往高处避一下看全貌时,可随时点「**升回安全高**」把刀抬回 `Z=0`。

### Step 6 —— 读门顶 Δ 与建议值

每次回到内环门,门顶回显都会实时刷新(内容详解见 §4)。当刀尖已经对准物理板角时,记下门顶给的**建议 plate_origin 新值**:

- 建议值 = **对准物理板角后的「当前实读 X/Y」直接照抄**。回显会写成 `建议 plate_origin: x→<数> y→<数>`。
- 系统**只显示不回写** —— 它不会自动去改配置,防止 run 上下文越权改标定。

### Step 7 —— 结束对位

点「**结束对位**」。流程会自动把刀升回 `Z=0`,回零(刀头绝不停在板上方),然后松开压板、抬定位气缸,把板放开。对刀流程结束。

### Step 8 —— 改配置,复跑验收

1. 到配置页,把 `gcode.plate_origin_x` / `gcode.plate_origin_y` 改成 Step 6 记下的建议值(手工誊抄)。
2. **复跑一次「刮板-对刀」**,重新走原点角 + 缓降,确认这次刀尖正对物理板角、门顶 `Δ ≈ 0`。Δ 收敛到接近 0 即验收通过。

## 4. 门顶回显那行字怎么读

内环每次回到门,顶部会显示一行由 `align_check.py` 预格式化好的中文,例如:

```
对位检查 — 当前 X=91.7 Y=-74.9 Z=18.0 (mm, Z向下) | 原点角=(91.24, -75.2) Δ=(0.46, 0.3) | 检查高度 Z=18.0 | jog 对准原点角后建议 plate_origin: x→91.7 y→-74.9 (只显示不回写, 到配置页人工修改)
```

逐段拆解:

- **当前 X/Y/Z**:三个轴的实读位(ActPos)。Z 越大越靠近板。
- **原点角=(…, …)**:配置里当前的 `plate_origin_x/y`,即程序认为的原点。
- **Δ=(Δx, Δy)**:当前实读 − 原点角。你**还没**对准板角时,它反映刀头离程序原点多远;你**已经**把刀尖对准物理板角后,它就是原点角当初标错了多少。
- **检查高度 Z=…**:这次缓降会停的高度(= `plate_surface_z_mm − align_clearance_mm`)。
- **建议 plate_origin: x→… y→…**:对准板角后照抄这两个数到配置页。

## 5. 遇到「点了不动 / 报错」怎么办(两级拒动)

机床动作里内置了守卫,不合规的指令会被**拒动**而不是硬闯。常见两类:

1. **XY 移动被拒**:只有刀在 `Z=0` 安全位时才允许 XY 平移;若刀不在 `Z=0`(比如还停在检查高度)就点走位,会被拒动。
   解决:先「升回安全高」再走。此外目标若超出板区软限位窗(板区 + 余量)也会被拒。
2. **缓降被拒**:只有 XY 已经落在板区窗内时才允许缓降检查高度;若刀还没走到板区上方就点缓降,会被拒。

被拒动时,流程**不会退出、也不会 fault**,只是回到内环门让你重选。被拒动后门会**原样重新弹出**(位置不变即未移动);具体拒动原因请到**运行日志 / 动作执行面板**查看。拒动原因在门内直显是留后升级项(需 VM catch 错误绑定)。
调用方(对刀业务)对内环失败有兜底:万一内环真的异常中止,会**先自动回零(刀头绝不悬在板上方),再松压板放板**,然后干净地报中止。

## 6. 和「包1 受力刮痕法」「刮后对账照片」的关系

这三件事互补,谁也不取代谁(见设计 spec §9):

- **本对刀流程(jog 对刀)**:取代了过去「包1」里靠牺牲一块板、刮一刀量 XY 原点的定量步骤 —— 现在不用再牺牲板就能标 `plate_origin`。
- **包1(受力刮痕 / 刮宽校验)**:仍保留它独有的价值 —— 静态对刀测不出「刀受力时的偏转」,受力刮痕能看真实刮削位置;
  同时还负责校验刮宽是否和 cutter compensation 半径 R 匹配。建议对刀改完 `plate_origin` 后,用包1**交叉验证一次**。
- **刮后对账照片(包2)**:刮完补拍、叠同一预览,是三链总偏差的长期**哨兵**,日常持续盯偏移用。

推荐顺序:**先 jog 对刀修 `plate_origin` → 包1 交叉验证一次 → 之后靠对账照片长期盯。**

## 7. 上机首核项与待验证清单

### 7.1 上机第一件要核的事:坐标帧一致性

在真机上跑之前,**第一项要核实的是:三个轴的实读位(ActPos)和配置里的 `plate_origin` 是不是同一套坐标系(同一坐标帧)。**
现场怀疑上位机的 `plate_origin`(例如 X 约 91、Y 约 −75)和 PLC 里 8Y 轴自己的坐标(例如 0…420 那套)可能不是同一帧。
如果不同帧,门顶算出来的 Δ 和建议值就不能直接照抄 —— 帧变换必须在 PLC 内部先做掉,让实读位和 `plate_origin` 落到同一套坐标里,
上面 §4 的 Δ/建议公式才成立。这一项在设计里被列为上机首要核查(内部代号 B1 核查 C2)。

### 7.2 其余上机待验证项(PLC 动作下装后逐条过一遍)

1. 走原点角后,门顶回显的坐标和刀头物理位置对得上;
2. 缓降 + jog 对准物理板角后,读出的 Δ 和「包1 卡尺法」交叉验证一次,量级一致;
3. 「走路径起点」走位(生产流程里)和手绘带目测吻合;
4. 改完 `plate_origin` 复跑,确认 Δ ≈ 0;
5. 故意给一个超出板区的目标 / 在低位给大步长,确认两级拒动都生效(PLC 报错在门里可见、回门不 fault);
6. 压下压板状态下,刀头在板区任意 XY + 检查高度,核查不会碰到压头或收集器(物理干涉核查)。
