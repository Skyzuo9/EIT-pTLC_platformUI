# 上样「过阀排空点样」流程 — 体积链与 PLC 对账

**日期**: 2026-07-25
**适用**: `sampling_execute`(上样-执行)现行编排 + PLC 工程 `20260702.project`(A50 / A55 / A62 已含气隔断与四指令版,rev0379 已手动下装)
**编写目的**: 把体积模型、逐步流路动作、上位机↔PLC 契约三者钉在同一份真源上,供真机标定与后续改动对照。

---

## 1. 为什么要改 — 旧流程的结构性损失

旧流程(`prep` 蓄驱动液 → `aspirate` 按名义体积吸 → `spot` 打到底)每轮固定把**三通到针尖的 1.125 mL 死体积**丢掉:样品被吸进针流路后,点样时三通切向点样头,这段被物理隔断,整段作废。

装 2 mL 样品时首轮只交付 `2.0 − 1.125 = 0.875 mL`,**交付率 44%**。

**新思路(过阀排空)**:多吸「样品 + 排空余量 E」,把整段样品**拖过三通**进入泵侧共管,针流路里只剩空气;切阀后推出的是共管里的样品,死体积不再参与。首轮交付率升到 ~100%(减去点样头支路的一轮滞留,下轮自动吐出)。

## 3. 体积模型

记 `V`=孔内样品 · `E`=排空余量 · `G`=气隔断 · `R`=润洗液 · `S`=喷出冗余 · `N`=点样活塞终点。

| 派生量 | 公式 | 缺省值 | 步数 |
|---|---|---|---|
| 首轮吸取 | `V + E` | 3.5 mL | P840 |
| 喷出冗余 `S` | `(E − D) + G/2` | 0.475 mL | — |
| 点样活塞终点 `N` | `G + E − S` = **`D + G/2`** | 1.225 mL | A294 |
| 润洗轮吸取 | `R + E` | 4.5 mL | P1080 |
| 气隔断 | `G` | 0.2 mL | A48 |

### 3.1 `S` 没有独立自由度

推出序列必须是「空喷段 `E − D` + 全部液体 + 一部分气隔断」。合法窗口是开区间 `(E−D, E−D+G)`,**宽度恰为 G**:

- 低于下界 → 样品尾巴推不完,留在共管
- 高于上界 → 推穿气隔断,把清洗液喷上板

取正中 `S = (E−D) + G/2`,两侧各留 `G/2`。代入 `N = G + E − S` 化简得 **`N = D + G/2`,与 E、V 均无关**,每轮同值。

> **不要找「喷出冗余」旋钮 —— 它已取消,改为 `op:assign` 派生。** 真机标定只调 `E`(空喷段 = E − D)与 `G`。

### 3.2 `N = D + G/2` 不是巧合

A55 的 `[1]` 从 `N` 打到 `A0`,推出量恰好等于「针流路气柱 `D` + 三通侧残余气 `G/2`」,所以针尖排出的**全是空气**,一滴清洗液都不进孔,同时针流路被共管清洗液重新填满。这条性质是第 5 节 `R` 全量入孔的前提。

### 3.3 润洗轮排空余量(2026-07-25 修正)

**曾经的错误**:`round_well_ml = R − 1.125`(自称「刻意低估、低估侧安全」)。由 3.2 可知针流路在加润洗液前已满液,`R` 全量入孔,不存在「空气置换」扣减。

按旧式,润洗轮实际多吸空气 = `(R − D + E) − R = E − D = 0.375 mL`,**恒 < D 且与 R 无关** → 液段没被整段拖过三通,每轮 0.75 mL 回收液卡死在针流路,多轮累积恶化。

**已改为** `aspirate_round_ml = R + E`,润洗轮排空余量恢复为 `E`,与首轮同构。

**吸完后的管内分布**:

```
针尖 0 ────1.125(三通)──────────────────────────────→ 泵腔
  [   空气 1.5   ][    样品 2.0    ][气0.2][ 清洗液 … A888=3.7mL ]
```

**关键不变量**:空气段 `E=1.5 > D=1.125` → 样品尾端已越过三通,整 2.0 mL 落在 loop 环侧。

**为什么吸气必须在移轴之前**:吸气前针尖内是满液,带液移动途中的挂壁滴液会滴进样品孔稀释样品。吸气后针尖端是空气段才安全移动。**顺序不可颠倒**,已真机验证(见 §7)。

**为什么用绝对 `A{G}` 而非相对 `P`**:润洗轮进入时 A55 已把活塞停在 `A{G}`,再绝对吸至同位是**零位移** —— 天然幂等,不需要「首轮吸 / 润洗轮跳过」的条件分支。

**点样头支路是移位寄存器**:喷出的 2.475 = 支路原存的 `B`(此时是清洗液)+ 序列前 `2.475 − B`;支路留下序列末 `B`,即 **0.1 空气 +(B−0.1)样品**。这部分下一轮开局吐出。

因为每程都扫过整条带,序列里的空气段只表现为「某几程空跑」,**不会在条带上留下空间断点**。

**Stage 2 终态**:针流路 1.125 空气 · 三通泵侧 0~0.1 残余气 · 泵腔 A294 = 1.225 清洗液 · 支路含首轮样品尾。

| 首轮 `spot_band_layer` | 439.5 s | 73% |
| 二轮 `spot_band_layer` | 420.9 s | 70% |

§3.3 的修正把二轮推出量从 2.35 提到 3.475 mL(**+48%**),程数与泵开时间同步线性放大:

- 按实测线性外推:`420.9 × 1.48 ≈ 623 s`
- 按第一性模型(L=170 mm,液体程 4.25 s + 吹干 17 s = 21.25 s/程;V6 → 0.10625 mL/程):二轮 33 程 ≈ 701 s

两种算法都**超过 600 s**。后果不是报错停,而是 `PLCActionOutcomeUnknown` → `TIMEOUT` +「结果不明确,禁止自动重发」,而 PLC 那边还在继续点样。

**已修**:`sampling.spot_band_layer` 加 `action_timeout: 1200.0`(≈ 二轮预估 623 s 的 2 倍余量)。这属于原设计疏漏:`stall_timeout` 从 60 提到 600 时,`action_timeout` 忘了一起提。

同批修 `sampling.rinse_mix`:它同样是 `stall_timeout: 600.0` 而绝对上限走全局 600 —— **两者同时到点,stall 永远轮不到触发,等于失效**。已加 `action_timeout: 900.0`(实际耗时约 100 s,900 只是兜底病态挂死)。

新增钉子 `test_slow_actions_raise_absolute_timeout_together_with_stall`:任何把 `stall_timeout` 提到 ≥ 全局 600 s 的动作,必须显式覆盖 `action_timeout` 且严格大于 `stall_timeout`。

> **残留边角**:缺省几何下 PLC 的 60 程上限 ≈ 1275 s > 1200 s,因此在"跑满 60 程"的病态场景里主机会比 PLC 的 **462** 早约 75 s 判 TIMEOUT。这个窗口很窄,且 60 程上限本身不是固定时长(随 `dry_cycles` 与扫线速度变化,`dry_cycles=2` 时可达 2295 s),没有任何固定 `action_timeout` 能保证 462 总是先浮出来。

### 6.2 `execute` 不校验入口活塞位

见 Stage 0 的警告框。A50 的 `[2]` 是绝对 `A{gap}`,活塞停在更高位时会反向打液从针尖喷出。目前靠「先跑准备」的操作纪律兜底。若要加守卫,合理位置是 A50 在发 `[2]` 前先查 `/4?`,发现当前位 > gap 就报错而不是反向打液。

### 6.3 `R + E` 的可达区间

`rinse_volume_ml` 旋钮域 `[1.5, 25]` × `over_aspirate_ml` `[1.2, 5]` 最大 30 mL,超过动作层 15 mL 硬闸。已在 `sampling_execute` 守卫里加了提前拦截分支(开跑前拒,不再跑到一半才拒),但面板上仍能填出会被拒的组合。未收窄旋钮域的原因:静态 `ui.max` 表达不了 `R + E` 的耦合,按 E 最坏值 5 把 R 压到 10 会在 E=1.2 时白丢 3.8 mL 合法量程。

### 6.4 flush 过冲余量偏小

`DEFAULT_FLUSH_ML = 17.0` 是 16.825 的 **1.01×**,只留 0.175 mL(1%)过冲。若实际使用中针尖偶有残气,把 flush 提到 18–20 是安全的(多出的从针尖排进废液位)。

### 6.5 `sampling.prep` / A40 保留

`prep` 动作与 PLC A40 **刻意保留**:legacy `sampling_full`、helper `sampling_spot` 仍引用,不属「孤立且不可达」;单动作调试也有价值。`sampling_execute` 已不再调用它。

注:`sampling.spot`(旧单次)的 `sample_volume_ml` 上限仍是 **12.0**,那是 v2 空气驱动策略 `peak = 2×sample + margin ≤ 25` 的正确结果(该策略样品进泵腔)。**不要与 `sampling.aspirate` 的 15.0 对齐** —— 两者约束来源不同。

## 8. 参数标定指南

**只需要调两个旋钮**:

| 旋钮 | 作用 | 调整判据 |
|---|---|---|
| `over_aspirate_ml` (E) | 空喷段 = `E − D`。**必须 > 1.125** | 条带起始段有明显空跑 → 调小 E(下限 1.2);样品尾巴推不干净 → 调大 |
| `air_gap_ml` (G) | 隔离样品与共管清洗液柱;同时决定 `N = D + G/2` | 板上末端出现清洗液稀释痕迹 → 调大 G;`N` 越界 [0,5] 会被守卫拒 |

`S` 与 `N` 全部派生,`spray_margin_ml` 没有旋钮。改 E 时 `S` 自动跟随,不需要联动手调。

`air_gap_ml` 在三处消费(`execute` 旋钮 / `prep.air_buffer_ml` / `rinse_mix.air_gap_ml`)统一取域 **[0.1, 1.0]**,由 `test_air_gap_knob_range_is_subset_of_every_consuming_action` 钉住包含关系 —— 旋钮域比动作域宽会造成「面板能填、跑到该动作才被拒」的不可达区间。
