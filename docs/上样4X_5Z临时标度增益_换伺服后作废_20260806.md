# 上样 4X 的临时标度增益(`scale_mm: 2.0`)—— 换伺服后作废

> 2026-08-06 立。**这是一个临时补偿,不是永久标定。**
> 4X 与 5Z 后续都要由 42CM08 步进换成伺服电机,届时轴标度重配,本增益必须归零。
> 看到 `rig_map.yaml` 里 `axis_4x.scale_mm: 2.0` 而不知其所以然的人,请先读完本文。

## 一句话

**上样 4X 这根轴上,"控制侧 1 mm" = "物理 2 mm"。**
三维侧用 `scale_mm: 2.0` 把这个差别补上,**真机分毫未动**。

## 它补的是什么

轴的标度(每毫米脉冲数)配成了实际所需的两倍 —— 等价说法:标度里的"每转行程"
被写成了实际机构的一半。于是控制侧命令 1 mm,机器走 2 mm。

前端换算式因此变成(`MachineStateDriver.axisUnitPerMm`):

```
δ物理 = (mm − zeroOffsetMm) × sign × scaleMm
```

`sign` 仍是纯方向(±1),增益单列。全机只有 `axis_4x` 的 `scaleMm ≠ 1`。

## 证据链(四条互不相干,最后一条是判决性的)

| 证据 | 比值 |
|---|---|
| 标定行距 9.0 vs SBS 孔距 18.00 | 2.00 |
| 标定两盘位间距 55.5 vs CAD 实测巢心距 112.0 | 2.02 |
| 48 孔最小二乘(标定目标 vs CAD 实测孔心) | 2.016(残差 0.274 mm) |
| **现场卡尺: 轴读 11.28 mm,实走 ≈22.6 mm** | **2.004** |

PLC 侧两点法实读(挪动前后 `IoConfig_Globals.上样轴4X轴`):

```
挪前  diActPosition = 0        fActPosition = 0.0000
挪后  diActPosition = 10528    fActPosition = 11.2800
⇒ Δdi/Δf = 933.33 增量/mm
```

对照各伺服轴(2²³ 编码器,`inc/mm = 8388608 / 导程`):

| 轴 | inc/mm | 每转 mm | 型号 |
|---|---|---|---|
| 地轨 11Y | 838,860.8 | 10 | CFF10-**L10**-900 ✅ |
| 点样 7Y | 838,860.9 | 10 | CFG4-**L10**-100 ✅ |
| 点样 6X | 1,677,722 | 5 | CFG4-**L5**-300 ✅ |
| 玻璃上料 1Z / 2Z | 1,677,721.6 | 5 | L5 ✅ |
| 刮板 10Z | ≈1,677,721 | 5 | CFG4-**L5**-50 ✅ |
| **上样 4X** | **933.33** | — | **自制同步带 + 42CM08 步进** |

4X 比伺服轴粗约 1800 倍,因为它**不是 SV660N 伺服** —— 整机只有 8 台
`InoSV660N_1..8` 却有 11 根轴,4X / 5Z 走的是另一套驱动,标度另配、也就配错了。

## 最重要的一条:**标定表和示教表都是对的,别去"修"它们**

在 2× 口径下,控制侧的数字逐项对上物理几何:

| 量 | 控制侧 | ×2 = 物理 | CAD 实测 |
|---|---|---|---|
| 行距 | 9.0 | 18.0 | 18.00(SBS) ✅ |
| 两盘位间距 | 55.5 | 111.0 | 112.0 ✅ |
| 清洗池离针 | 78.4 | 156.8 | 156.85 ✅ |

最后一行顺带解开了 `rig_map.yaml` 里记了很久的那处「未解释的差」——
「清洗池离针 156.85 mm,而 4X 限位跨度只有 115 mm,走不到」:在 2× 口径下
156.85 物理 = 78.4 控制 mm,稳稳落在 `[−5, 110]` 内。

⇒ `config/calibration.yaml`、HMI 示教表、PLC 代码**全都没错**,
它们是在真机上按真机的单位教出来的。**唯一错的是轴标度。**
(2026-08-05 前几轮里"标定值可疑 / 可能是占位值"的判断,到此全部撤销。)

## 为什么现在不改真机

机器目前是**自洽可用**的:标定、示教、软限位全都在同一套半毫米口径里,业务跑得通。
改标度要在同一次里把下面全改对,漏一个针就扎错地方,而板已经在盘位上:

- HMI `HMI_上样轴4X轴.position[1..8]`:23 / 32 / 41 / 50 / 78.5 / 87.5 / 96.5 / 105.5
- `config/calibration.yaml` 的 `plate_4x6_1` / `plate_4x6_2` 各 3 个点
- `config/points/plc/sampling.yaml` 的 `sampling_4x` 软限位 `[−5, 110]`
- 以及任何按 4X mm 写死的动作参数

所以选择:**先档案化,择停机窗口整改。**

## 退役清单(换伺服时逐条勾)

- [ ] 新伺服按**实际机构**配标度;配完用两点法复核(挪一段,读
      `IoConfig_Globals.上样轴4X轴` 的 `diActPosition` / `fActPosition`,`Δdi/Δf` 即 inc/mm)
      —— **别只信配置页**,这次就是配置页看着没问题;
- [ ] 卡尺量一次实际位移,确认 `fActPosition` 的读数就是物理毫米;
- [ ] `rig_map.yaml` 的 `axis_4x.scale_mm` 改回 **1.0**;
- [ ] **4X 的示教值不是简单 ×2 就完事** —— 换电机后零点与行程都变,
      按 `three_d/docs/AXIS_ZERO_CALIBRATION.md` 七步法重新标零,再重走
      `/points/calibration` 的孔板 3 点标定;
- [ ] 软限位按新口径重定(物理跨度参照 `rig_map` 的 `stroke_mm: 319`);
- [ ] `rig_map` 的 `axis_4x.zero_offset_mm`(现 77.68)与 `range_mm`(现 `[−15.75, 143.75]`)
      随之重解 —— 注意 `range_mm` 是**控制侧 mm**、`stroke_mm` 是**物理 mm**,差一个增益;
- [ ] 重跑三维链,`verify_sample_plates` 的孔位可达判据应仍全绿;
- [ ] 删掉本文档,或在顶部标注"已作废 + 作废日期"。

## ⚠ 5Z 的标度**至今未验**

5Z 与 4X 同型(自制同步带 + 42CM08 步进,同样不是 SV660N)。三次 OPC 实读时
`上样轴5Z轴.diActPosition` 都恰好是 0,**除不出比值** —— 它的标度对不对,目前**没有证据**。

2026-08-06 把 `axis_5z` 定成 `sign: -1` / `zero_offset_mm: 48.5`,是**在增益 1.0 的前提下**
让三个示教位(抬起 0 / 升降 45.0 / 下探 46.5)落到合理处的。若 5Z 也有 2×,那组值同样会偏,
而且**当时分辨不出来** —— 增益 2 时抬起位会到板顶上方约 55 mm,物理上也说得通。

**建议在换伺服之前先测一次**,做法与 4X 完全相同:把 5Z 从 0 挪到某个非零位,读
`diActPosition` / `fActPosition` 得 inc/mm,再拿卡尺量一次实际位移。
5Z 是**垂直轴且针要扎进孔**,标度错的后果比 4X 更直接 —— 现在板已经在盘位上了。
