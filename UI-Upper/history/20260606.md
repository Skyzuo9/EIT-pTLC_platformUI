# 2026-06-06 实验日志

## 修改目标
液位检测模块 SSH 远程管理集成、CNC 路径列数算法修正、上样打液速度独立控制、TankVisionDialog 参数面板重构。

## 核心改动
- 新增 `core/orangepi_manager.py`：SSH 到香橙派启停液位检测脚本，MQTT online 确认，进程退出前自动远程 kill。
- `water_level_client.py`：新增 `force_cleanup()` 幂等清理 + `atexit` 注册 + `loop_stop` 超时保护 + 3 个新 MQTT 命令（set/get_calibration, capture_reference）。
- `cnc_path_generator.py`：`_compute_coverage_columns` 搜索方向由"≤ ideal 最大因子"改为"≥ ideal 最小因子"，解决 n_points=400 时覆盖不足告警。
- `sample_pump_translator_v2.py`：新增 `DEFAULT_DISPENSE_DISP_SPEED=50`，点样打液速度独立于通用 disp_speed。
- `tank_vision_dialog.py`：参数分组重构（液位边缘/前沿对比/流动方向/高级设置折叠），新增 debug 视图模式。
- `debug.py`：液位参考图拍摄按钮、`ui.notify` 全部改为 `_notification_queue`、`open_vision_dialog` 改 `await` 修复 slot context 丢失。
