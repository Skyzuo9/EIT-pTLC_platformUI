# 2026-06-08 实验日志

## 修改目标
实现多 Band 刮取 V3 锁非对称结构（协议 v1.8），将多 band 序列从「Phase 2-4 全锁」重构为「锁内 N scrape + N-1 collect，末次 collect 锁外执行」；同步 Debug Tab 一键清零、大恒相机光源控制、配方默认值漂移对齐、液位模块重构。

## 核心改动
- **V3 锁非对称结构**：`RecipeTask` 在 `_scrape_lock` 内执行 N 次 scrape + N-1 次 collect；末次 scrape 写 `scrape_IsLast=TRUE`（PLC 送板废料区），之后释放锁，第 N 次 collect 在锁外执行——BeforePhoto 可抢占空工位。
- **ScrapeStage is_last_band 机制**：新增 `_resolve_is_last()` + `_send_params_with_is_last()`，所有 Step 15 Confirm 前的参数下发自动注入 `scrape_IsLast`；重刮 `PhotoMode=2` 跳过 A00 复位 + A10 拍照。
- **视觉失败路径增强**：失败时推送 `enriched_ar`（含图像路径）到 Vision Tab，激活手动 band 选择 + 历史分析加载；`_wait_for_band_selection_and_build_params()` 替代原来的安全占位直发。
- **耗材预检 + handoff 校验**：Phase 1 前调 `check_availability()` 提前拦截耗材耗尽；`_scrape_lock` 内 release 前双重校验（`bound_tank == pending` + `handoff_pending=True`）。
- **Mock FSM 对齐**：Step 15 为唯一乒乓点（`confirm_steps={15}`），Step 20/30 无乒乓自动推进；新增 `scrape_Source_Tank` 诊断节点；耗材控制台解码改 1-6 数字编号。
- **Debug Tab 一键清零**：`_RESET_VAR_DEFS` 分组定义（BOOL/数组/CNC 大数组），变量级容错（单个写失败跳过不报错），确认对话框区分 mock/实机环境。
- **render_scrape_arrays_path**：从 ScrapeArrays 直接渲染 PLC 实际消费点位路径 PNG，与 `render_gcode_path` 互补。
- **大恒相机光源控制**：config 新增 `auto_light_control`（拍照前开灯/拍后关灯保护光源）+ `light_line`（GPIO 光耦线选择）。
- **配方默认值漂移**：`num_passes=1`（原 3）、`overlap_ratio=0.4`（原 0.8）、`solvent_channel=2`（原 1），`camera.mock=false`。
- **Recipe UI**：耗材板号改 1-6 整数编号（v3 编号体系对齐），`sorted()` + `int()` 存储。
- **液位模块**：8ch MQTT 脚本大幅重构 + debug 可视化设计文档更新；tank_vision_dialog 新增 SNR/diff 阈值参数。
