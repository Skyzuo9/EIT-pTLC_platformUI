# 2026-05-21 实验记录

## 修改目标

在 Flow Tab 中新增"系统总览"(Dashboard) 视图，实时展示 4 大物理工位并发占用状态 + 8 缸网格，为多样品并发调度提供全局态势感知。

## 核心改动

1. **`ui/sections/flow.py`** (+340 行)：
   - 新增 `dashboard` toggle 选项，渲染 2×2 物理工位卡片布局
   - `_render_station_card()`：通用工位卡片（spotting/scrape/collect），显示 running/idle/error/estop 边框 + 占用样品 + 排队折叠
   - `_render_develop_station()`：展开工位特殊渲染（2 组 × 4 缸彩色网格，状态色块 + tooltip）
   - `_derive_waiting_for_station()`：从 log_store 事件流推导各工位排队等待样品
   - 指纹脏检查（`_compute_dashboard_fingerprint`）：避免无意义 DOM 重建导致 `ui.expansion` 折叠
   - before_photo + scrape 合并为"拍照刮板"物理工位展示

2. **`ui/app.py`** (+18/-3 行)：
   - `_periodic_refresh` 新增周期 `rm.sync_states()` 调用（1s 节流），保持 dashboard 展缸状态新鲜
   - Flow 脏检查段新增 dashboard 模式跳过逻辑（C1 修复）

3. **`core/resource_manager.py`** (+4 行)：
   - 新增 `all_tank_info() → dict[int, TankInfo]` 方法，供 Dashboard 渲染消费
