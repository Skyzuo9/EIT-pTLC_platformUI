# 2026-06-01 CNC 点位容量升级 + 策略裁剪 + 覆盖率自动推导

## 修改目标
解决 CNC 路径生成器在最小铣刀（1mm）+ 大尺寸条带（~200mm）下覆盖率不足的问题，同时清理不符合需求的 sinusoidal 策略。

## 核心改动
1. **点位容量 80→200**：`SCRAPE_POINT_COUNT` / `COLLECT_POINT_COUNT` 从 80 升至 200，PLC `NODE_ARRAYS`、mock server、CNC 模板（v2.2）同步更新
2. **删除 sinusoidal 策略**：该策略仅在 bbox 内画正弦波，不跟随条带实际轮廓，与"刮取特定形状条带"的根本目标冲突。策略表收敛为 zigzag（回归基线）/ boustrophedon（无轮廓 fallback）/ contour（生产唯一推荐）
3. **铣刀覆盖率自动推导**：新增 `_compute_coverage_columns()` 根据 `cutter_diameter × (1 - overlap_ratio)` 自动计算最优列数，保证铣刀覆盖无遗漏；覆盖不足时 `log.warning` 告警
4. **boustrophedon_columns 降级为提示**：不再强制使用用户配置的列数，自动推导优先
