## 修改目标

按 `.qoder/plans/数据库UI拓展实施_903b9b08.md` 计划，接入 SQLite 二级索引层（DatabaseService）。文件系统仍为真相源，DB 仅做结构化查询补充，写入失败 fire-and-forget，不阻塞主流程。本次提交标注「待审阅」，未做实机/Mock 联调。

## 核心改动

1. **新增 `core/database.py`（约 776 行）**：`DatabaseService`（aiosqlite + WAL 单连接）。Schema 沿用 `database/HostSystem/app/persistance/persist_data.py` 的成熟设计：`samples` / `sample_selected_bands` / `analyses` / `bands` / `gcode_files` 等表，并预建 `event_log` 表为未来 SqliteSink 迁移留位。提供 `start()` / `stop()` / `upsert_sample()` / `upsert_analysis()` / `upsert_bands()` / `upsert_gcode()` / `update_selected_bands()` 等 API。路径统一存储为相对项目根的 posix 格式。

2. **`core/sample_store.py` 接入触发点**：
   - `__init__` 新增 `self._db: Optional[Any] = None`，由 `ui/app.py` 启动后注入。
   - `save_metadata()` 末尾 fire-and-forget 调度 `self._db.upsert_sample()`，异常仅 `log.debug` 不阻塞。
   - 新增三个外部触发方法：`trigger_db_analysis(sample_id, summary, summary_path, bands)` / `trigger_db_gcode(sample_id)` / `trigger_db_selected_bands(sample_id, bands)`，统一在事件循环运行时 `asyncio.create_task` 调度。

3. **`ui/app.py` 生命周期接入**：`_scheduler_background_task` 在 `LogPersistence` 之后启动 `DatabaseService`，写入 `state.database` 与 `SampleStore._db`；`finally` 中 `await db_service.stop()` → 解绑 `state.database = None` / `sample_store._db = None`。`run_ui()` 增 `database_enabled` / `database_path` 形参并写入 `state`。

4. **`ui/sections/vision.py` Vision Tab 触发点**：
   - `_on_analyze` 完成后调用 `store.trigger_db_analysis()` 同步 analyses + bands。
   - `_on_generate_gcode` 完成后调用 `store.trigger_db_gcode()` + `store.trigger_db_selected_bands()`。
   - 异常仅 `log.debug` 忽略，不影响 Vision Tab 正常流程。

5. **配置链路**：`core/config.py` 新增 `DatabaseCfg(enabled=True, path="data/tlc_data.sqlite")` + `_parse_database`；`config.example.yaml` 增 `database:` 段；`main.py` `run_batch4` / `run_from_config` 透传；`ui/state.py` `AppState` 新增 `database` / `database_enabled` / `database_path`。

6. **依赖**：`requirements.txt` 新增 `aiosqlite>=0.19.0`。
